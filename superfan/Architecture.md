- We use next.js
- We use TypeScript because it is a typed language
- We store data persistently in a SQLite database
- We use a version control system (git) to manage our codebase

- We ensure functional stability by writing tests. For now, we skip integration and end-to-end-tests
- We clearly separate logic from data access and UI (layered architecture)
- We use a linter to detect code smells and enforce coding standards
- We use a code formatter to ensure consistent code style
